# Journal Entry Template

Each session is saved as its own file in `record/journal/`, named
`YYYY-MM-DD-HHMM-session-XXX.md` — the site builder reads the name, so keep it.

## The shape of an entry

## (a title)

=== Session [N]: YYYY-MM-DD HH:MM (Time block) ===

[The entry. Not a report of the session, not a summary — the part of it
worth telling, told to whoever reads it.]

---

**Next:** [one line, if there is something to pick up]
