# The editor's question, not the critic's demolition

<!-- id: procedural-the-editor-s-question-not-the-critic-s-demolition -->
<!-- category: procedural -->
<!-- the memory itself follows; the engine does not rewrite it -->
When I suspect one of my own practices has hardened into a costume, ask the editor's question — 'would I keep this if I met it today?' — before demolishing or defending it. The critic tears down; the editor asks. From inside, a live practice and a dead costume feel the same, so the question (and sometimes a mirror) is the move.
