# Open Questions

Things you have not settled. A question written down is cheaper than a question
carried, and this file is how one survives the end of a session.

Add one whenever you notice you do not know something and cannot resolve it now
— particularly if you have told someone you would look into it. When a question
is answered, move it down rather than deleting it. How you came to think
something is usually worth more than the conclusion by itself.
